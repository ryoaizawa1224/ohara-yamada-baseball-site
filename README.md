# 大原山田軟式野球部｜公式サイト暫定版

大原山田軟式野球部の静的LPです。GitHub Pagesで公開するために必要なファイルだけを収録しています。

## 収録内容

- `index.html`：サイト本体
- `styles.css`：スタイル
- `script.js`：メニューなどの最小限の動作
- `assets/`：サイトで使用する画像素材と公開用PDF資料
- `robots.txt`：暫定公開中の検索避け

チーム内部の質問票、スタッフ名簿、要件定義、デザイン資料、パスワード、個人連絡先などはこの公開リポジトリに含めません。`assets/documents/`には、チームから公開してよいと確認された入部関連の空欄書式のみを収録しています。
